### F-004 — `href` rendered from API response without an explicit same-origin assertion

- Source: checklist/input (defense-in-depth note, not exploitable today)
- Severity: Low
- File: `apps/web/src/components/ProgramCard.tsx` / `ProgramCardLink.tsx`
- Detail: `card.href` is consumed verbatim into a plain `<a href={href}>` (no `dangerouslySetInnerHTML`, no `javascript:` sink — React's JSX attribute binding is not an XSS vector here). The value is produced server-side as a literal `f"/programs/{row.program_id}"` (`program_board.py:134`) from a DB-sourced `program_id`, never from unsanitized user input, so no live open-redirect/XSS path exists. Flagging only because the frontend has no independent validation that `href` is a relative, same-origin path if the backend contract were ever violated.
- Fix (non-blocking): optional future hardening — assert `href.startsWith("/")` client-side, or add a schema-level pattern constraint on `ProgramBoardCard.href` in `program_board.py`.

## Manual OWASP checklist — key results

- **AuthZ (core risk)**: `GET /api/overview/program-board` gates with `org_access` (cio-only), NOT the open-aggregate `program_visibility` gate used by `program-detail/*` siblings. Verified in `app/api/overview.py:695` — `await org_access(current_user)` is the first statement in the handler body, executed before `fetch_program_board` (the only data read). `org_access` (`app/core/rbac.py:85-97`) fail-closed resolves persona (catches `PersonaNotFoundError`/`PersonaResolutionError` separately, both deny), denies with `HTTPException(status_code=403)` carrying **no `detail=`** (empty body — no data/error-message leak), and denies-by-default on any resolution failure. Confirmed via `test_program_board.py::test_non_cio_403_no_body_and_rbac_check_org_access_logged_tc05` — asserts 403 across 5 non-cio personas with no body.
- **Broken access control / IDOR**: The endpoint takes no `program_id` param — it is intentionally org-wide once `org_access` passes. `page`/`page_size` cannot widen/narrow program scope; they only paginate the already-authorized full result set. No IDOR surface.
- **Injection**: `fetch_program_board` (`app/services/program_board.py:142-166`) uses SQLAlchemy Core `select()`/`.order_by()`/`.offset()`/`.limit()` — no string-built SQL, no f-string SQL. Confirmed no hits in SAST grep pass.
- **DoS / resource exhaustion**: `_board_page_params` (`overview.py:654-663`) uses `Query(1, ge=1)` / `Query(20, ge=1)` then `min(page_size, MAX_PAGE_SIZE)` (100) in code — not documentation-only. `page<1`/`page_size<1` reject 422 (`test_page_and_page_size_below_1_rejected_422_tc10`); above-100 clamps rather than rejects (`test_pagination_default_and_clamp_above_100_tc09`). No path bypasses the clamp (single dependency, no alternate param name). `_validate_sparkline` (`program_board.py:41-65`) never raises on hostile/malformed JSONB — explicitly guards non-list, non-dict elements, missing keys, wrong types, and the `bool`-is-`int` subtype trap; falls back to `[]` on any deviation. Matches research C-2/R-02 mitigation. Confirmed via `test_null_missing_malformed_sparkline_falls_back_to_empty_tc03` and `test_validate_sparkline_never_raises_on_deviant_shapes`.
- **Sensitive-data exposure in logs**: `rbac_check_org_access` logs only `user_id` (opaque identifier) and `persona` (role name) — enforced structurally by `_EVENT_REQUIRED_FIELDS`/`_EVENT_OPTIONAL_FIELDS` allowlists in `rbac.py:316-325`, which raise `AssertionError` on an unrecognized field. No PII, no token, no email. Matches `.claude/rules/security-baseline.md` logging invariant.
- **Frontend `console.info`**: `ProgramCardLink.tsx:39` logs `{event:"program_drilldown", program_id}` — `program_id` is an opaque, non-sensitive resource identifier already visible in the URL/DOM; not PII, not a credential. No leak.
- **XSS / unescaped HTML**: No `dangerouslySetInnerHTML`, no `innerHTML=`, no `document.write` in the diff (SAST grep, zero hits). All dynamic text (`card.name`, `card.description`, `card.type`, `card.icon`) renders via JSX text interpolation, which React auto-escapes.
- **Dependencies**: No new runtime dependency added — confirmed empty diff on `services/api/pyproject.toml`, `services/api/uv.lock`, `apps/web/package.json`, `apps/web/pnpm-lock.yaml` for this branch vs `origin/main`.
